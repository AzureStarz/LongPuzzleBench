# Puzzle suite notice

This directory contains the source and prebuilt browser bundle for the six
LongPuzzleBench environments. It was integrated from the `hongbin` branch of the
[`Bolt_Unscrew`](https://github.com/adf1178/Bolt_Unscrew/tree/hongbin) project,
based on revision `282ad0b`, without its Git metadata, generated editor state,
dependency cache, or temporary build state.

Benchmark-specific work adds the evaluator-only bridge, calibrated task data,
progress metrics, deterministic launch parameters, and the Maze Paint and Color
Connect environments. No standalone license file was present in the imported
source branch. The repository-level Apache License 2.0 therefore applies only
to material for which the LongPuzzleBench contributors hold the necessary rights;
